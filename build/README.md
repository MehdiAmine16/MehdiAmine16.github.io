# Building the portfolio page

`index.html` is generated. Edit the sources here, then run:

    node build/build.mjs

- `content.json` — timeline entries and projects (each project's `d` = its case study)
- `style.css` — page styles
- `header.html`, `outside.html` — hand-written blocks
- `build.mjs` — turns all of the above into `../index.html`
